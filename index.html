Sinkronisasi Multi-User Cloud (Google Sheets / Cloud API)

Hubungkan aplikasi Anda ke cloud terpusat agar seluruh karyawan yang mengakses via link Netlify dapat melihat dan menyimpan transaksi bersama secara real-time tanpa biaya server bulanan.

Mode Lokal
Salin URL Web App dari Google Sheets perusahaan Anda (lihat panduan 1 menit di bawah).

Cara Menghubungkan Google Sheets untuk Multi-User (Gratis Selamanya):

  1. Buka Google Drive akun perusahaan, buat 1 spreadsheet baru bernama Database AkuntansiPro.
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Hapus kode bawaan, lalu copy-paste seluruh isi file script google_sync_script.gs yang sudah disediakan di folder proyek ini.
  4. Klik tombol biru Deploy → New deployment, pilih tipe Web app, atur Who has access menjadi Anyone, lalu klik Deploy.
  5. Salin (Copy) Web App URL yang dihasilkan, tempelkan ke kolom input di atas, lalu klik Simpan Konfigurasi Cloud. Selesai! Semua staf di Netlify kini tersinkron 100%!

Pemeliharaan & Keamanan Data (100% Offline-Safe & Terenkripsi)

Semua data Anda tersimpan aman dan terenkripsi pada browser komputer ini. Anda dapat mengunduh salinan cadangan lengkap kapan saja dalam 1 klik.

🔒 Cadangan Database Terenkripsi Kata Sandi (Security Enkripsi)

Enkripsi seluruh database pembukuan dengan kata sandi rahasia sebelum diunduh (.enc.json). File tidak dapat dibaca siapa pun tanpa kata sandi Anda saat proses pemulihan.

1. Backup Cadangan Database Biasa

Unduh seluruh transaksi, COA, saldo, invoice, dan master data ke dalam file file JSON standar.

2. Restore Database dari File

Pulihkan data pembukuan dari file backup JSON sebelumnya.

3. Reset Bersih Database

Hapus seluruh data simulasi transaksi untuk memulai pembukuan riil perusahaan dari awal.
